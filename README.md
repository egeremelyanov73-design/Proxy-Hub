# Proxy Hub (Android)

Менеджер конфигураций прокси/VPN на Kotlin + Jetpack Compose.

## Что умеет
- **Вставить из буфера обмена** — понимает `happ://add/https://…`, обычную ссылку подписки `https://…`
  и одиночные `vless:// vmess:// trojan:// ss:// hysteria2:// tuic://`. Можно вставить несколько ссылок сразу.
- **Сканировать QR-код** — через сканер Google Play Services.
- **Кнопка «Открыть в Happ» в боте** — приложение зарегистрировано на `happ://`, `vless://`, `vmess://`,
  `trojan://`, `ss://`. Если установлен и настоящий Happ, Android предложит выбрать, чем открыть.
- **Подписки** — загрузка списка серверов (base64 или обычный список), имя берётся из заголовка `profile-title`,
  кнопка обновления подписки.
- **Настройки → «Настройки тем»** (самый верх): выбор 5 цветов, вставка темы из буфера (JSON),
  копирование и сброс. Формат темы:
  `{"bg":"#12141a","panel":"#1d2029","accent":"#4f8cff","text":"#e8eaf0","muted":"#8a90a0"}`

## Как собрать
1. Откройте папку в Android Studio (Koala или новее), дождитесь синхронизации Gradle.
2. Run ▶ на телефоне или эмуляторе с Google Play (сканер QR требует сервисы Google).
3. APK: Build → Build Bundle(s) / APK(s) → Build APK(s).
